# راهنمای دری بستهٔ LSS

LSS یک بستهٔ قابل‌استفاده در پروژه‌های دیگر برای ذخیره‌سازی رمزنگاری‌شدهٔ داده در حالت آفلاین و ارسال آن هنگام دسترسی به سرور است. نسخهٔ نخست دو پیاده‌سازی دارد: JavaScript با تعریف نوع برای TypeScript، و Python. هر دو از یک قرارداد ارسال و قواعد مشترک استفاده می‌کنند.

این بسته به فورم‌های ساختمانی NBCC محدود نیست. شما می‌توانید دادهٔ پروژهٔ خود، مانند گزارش فعالیت، موجودی یا ثبت سفارش کوچک را به آن بدهید. قواعد تجارتی، ورود کاربران و صلاحیت دسترسی به داده‌ها را برنامهٔ شما تعیین می‌کند.

## وضعیت نسخه

این نسخه یک پیش‌نمایش پژوهشی است. بسته با نام `lss-sync` در npm و PyPI قابل نصب است. مخزن پروژه در GitHub با آدرس https://github.com/Kingsum007/lss قرار دارد.

## الگوریتم چه کار می‌کند؟

1. داده را بررسی می‌کند و برای آن یک شناسهٔ ثابت می‌سازد.
2. پیش از ذخیره‌سازی، محتوا را با AES-256-GCM رمزنگاری می‌کند.
3. دادهٔ رمزنگاری‌شده و وضعیت ارسال آن را در یک تراکنش محلی ثبت می‌کند.
4. وقتی برنامه باز و قفل‌گشایی‌شده باشد، بسته‌های کوچک را به سرور می‌فرستد.
5. اگر اتصال قطع شود یا پاسخ سرور نرسد، همان شناسه را دوباره می‌فرستد. سرور سازگار، این تکرار را به‌عنوان ثبت جدید قبول نمی‌کند.
6. فقط پس از تأیید رسید سرور و ذخیرهٔ آن در دستگاه، وضعیت داده «تأییدشده» می‌شود.

اندازهٔ بسته از ۲ کیبی‌بایت شروع می‌شود و حداکثر ۱۶ کیبی‌بایت است. پس از دو ارسال کامل و سریع، اندازه کمی افزایش می‌یابد؛ پس از ارسال کند یا ناموفق، کاهش می‌یابد. این اندازه شامل تمام بدنهٔ درخواست است، نه فقط متن داده.

## نصب بسته

برای نصب بستهٔ مرورگر در پروژهٔ JavaScript یا TypeScript خود:

```powershell
npm install lss-sync
```

برای Python نسخهٔ 3.10 یا بالاتر:

```powershell
python -m pip install lss-sync
```

نصب وابستگی‌ها معمولاً برای بار نخست به اینترنت نیاز دارد. پس از نصب و آماده‌شدن برنامه، ثبت آفلاین به اتصال سرور وابسته نیست.

## استفاده در JavaScript و TypeScript

```javascript
import { BrowserSyncEngine } from 'lss-sync';

const sync = new BrowserSyncEngine({
  dbName: 'my-project-vault',
  endpoint: '/api/sync',
  token: accessToken
});

const { configured } = await sync.init();
if (configured) await sync.unlock(passphrase);
else await sync.setup(passphrase);

await sync.save({
  type: 'inventory-entry',
  item: 'cement',
  quantity: 24
});
```

`accessToken` و `passphrase` متغیرهای برنامهٔ شما هستند؛ آن‌ها را از کاربر یا سیستم احراز هویت بگیرید و در سورس کد ثابت ننویسید. برنامه باید از HTTPS یا محیط محلی امن مرورگر باز شود. سرور مثال‌ها قرارداد LSS را پیاده می‌کند؛ یک API معمولی بدون رسید سازگار، برای این بسته کافی نیست.

مرورگر از IndexedDB برای نگهداری محلی استفاده می‌کند. بستهٔ مرورگر در محیط Node.js دارای همان امکانات ذخیره‌سازی مرورگر نیست؛ برای برنامه‌های Python از بستهٔ جداگانهٔ Python استفاده کنید. راهنمای اصلی مخزن، رابط‌ها و تعریف‌های TypeScript را توضیح می‌دهد.

## استفاده در Python

```python
from lss_sync import SyncClient

client = SyncClient(
    "queue.sqlite3",
    endpoint="https://your-domain.example/api/sync",
    token=access_token,
)

if client.configured:
    client.unlock(passphrase)
else:
    client.setup(passphrase)

client.save({"type": "inventory-entry", "item": "cement", "quantity": 24})
client.start()

# برنامه باید در حال اجرا بماند تا ارسال خودکار ادامه پیدا کند.
# هنگام بستن برنامه:
# client.close()
```

`start()` در Python ارسال‌کنندهٔ پس‌زمینه را آغاز می‌کند. برای کنترل دستی یک نوبت ارسال، `sync_once()` موجود است. `stop()` زمان‌بندی را متوقف می‌کند؛ `lock()` کلید را از دسترس بسته خارج می‌کند؛ `close()` برنامهٔ ارسال را متوقف و محل ذخیره را قفل می‌کند. کلید خام و گذرواژه در دیتابیس ذخیره نمی‌شوند.

## دادهٔ قابل‌قبول

داده می‌تواند شامل متن، عدد صحیح امن، مقدار منطقی، `null`، آرایه و آبجکت JSON باشد. اعداد اعشاری را به شکل متن بفرستید؛ مثلاً `"1250.75"`. فایل، عکس، آبجکت‌های ویژهٔ زبان و ساختارهای حلقوی در این نسخه پشتیبانی نمی‌شوند. یک عملیات باید با تمام معلومات درخواست در حد ۲ کیبی‌بایت جا شود؛ دادهٔ بزرگ پیش از اعلام ذخیره‌شدن رد می‌شود.

برای بررسی قرارداد دقیق بین زبان‌ها، [PROTOCOL.md](PROTOCOL.md) را بخوانید. افزودن زبان جدید باید با همان نمونه‌های مشترک و آزمایش‌های سازگاری انجام شود.

## حدود مهم

رمزنگاری، محتوای ذخیره‌شده در دستگاه را محافظت می‌کند. سرور مجاز پس از ارسال از طریق HTTPS می‌تواند محتوا را بخواند. این طرح، رمزنگاری سرتاسری‌ای نیست که داده را از سرور پنهان کند.

در قطع کامل اینترنت ارسال ممکن نیست؛ داده در صف می‌ماند. در مرورگر، برنامه باید باز و قفل‌گشایی‌شده باشد. در Python، پروسه و ارسال‌کننده باید فعال باشند. پاک‌شدن حافظهٔ مرورگر یا گم‌شدن گذرواژه می‌تواند بازیابی دادهٔ ارسال‌نشده را ناممکن کند.

ارزش عملی این پروژه، فراهم‌کردن یک بستهٔ کوچک با رفتار قابل‌آزمایش و مستندات روشن است. ارزش پژوهشی آن باید با مقایسهٔ اندازهٔ بسته‌ها، زمان ارسال، مصرف منابع و بازیابی پس از خطا نشان داده شود. استفاده از دو زبان، به‌تنهایی اثبات نوآوری الگوریتم یا برتری سرعت نیست.
