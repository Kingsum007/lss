# LSS

Lightweight offline-first synchronization SDK for JavaScript/TypeScript and Python, featuring encrypted local storage, adaptive batching, and safe retries over unreliable connections.

## Installation

JavaScript/TypeScript (browser SDK):

```sh
npm install lss-sync
```

Python 3.10+:

```sh
python -m pip install lss-sync
```

Packages: [npm](https://www.npmjs.com/package/lss-sync) · [PyPI](https://pypi.org/project/lss-sync/).

This is a research preview. See the SDK guide for browser requirements, server integration, and security boundaries.
